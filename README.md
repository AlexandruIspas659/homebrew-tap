# homebrew-tap

Homebrew formulae for [AlexandruIspas659](https://github.com/AlexandruIspas659)'s tools.

```
brew install AlexandruIspas659/tap/ipcprobe
```

| Formula | What |
|---|---|
| `ipcprobe` | Discover and reconfigure TVT/OEM (e.g. DVC) IP cameras on a LAN — a cross-platform IPTool replacement. [Repo](https://github.com/AlexandruIspas659/ipcprobe) |

`Formula/ipcprobe.rb` is written automatically by GoReleaser on every tagged release of ipcprobe; don't edit it by
hand. Until the first release exists you can build from source with `brew install --HEAD AlexandruIspas659/tap/ipcprobe`.
