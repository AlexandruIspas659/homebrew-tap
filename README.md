# homebrew-tap

Homebrew casks for [AlexandruIspas659](https://github.com/AlexandruIspas659)'s tools.

```
brew install --cask AlexandruIspas659/tap/ipcprobe
```

| Cask | What |
|---|---|
| `ipcprobe` | Discover and reconfigure TVT/OEM (e.g. DVC) IP cameras on a LAN — a cross-platform IPTool replacement. [Repo](https://github.com/AlexandruIspas659/ipcprobe) |

`Casks/ipcprobe.rb` is written automatically by GoReleaser on every tagged release of ipcprobe; don't edit it by hand.
